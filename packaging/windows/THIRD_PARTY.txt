CloudMus for Windows bundles Qt 6.9.3, libmpv, the Vulkan loader,
CPython 3.13.7, MinGW runtime libraries and Python packages used by three
of its backends. The fourth, Spotify (backends\cloudmus-backend-spotify.exe),
is built from librespot and other Rust crates: their licenses are in
THIRD_PARTY-spotify.txt, alongside.

Qt: https://www.qt.io/licensing/open-source-lgpl-obligations
libmpv: https://github.com/mpv-player/mpv/blob/master/Copyright
Vulkan loader (vulkan-1.dll): VulkanRT-License.txt, alongside
TagLib 2.3.2 (tags and covers of saved tracks), statically linked, used
under the Mozilla Public License 1.1: https://taglib.org/ — source:
https://github.com/taglib/taglib/releases/tag/v2.3.2 (with utfcpp,
Boost Software License 1.0)
CPython: https://docs.python.org/3/license.html
MinGW-w64: https://www.mingw-w64.org/licensing/

Python package licenses and versions are recorded in the accompanying
python/Lib/site-packages/*.dist-info/ directories.

These components are dynamically linked or packaged as separate files,
except TagLib (above), which is statically linked.
Their source code is available from the linked upstream projects.
